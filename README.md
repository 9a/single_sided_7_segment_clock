# single_sided_7_segment_clock
A pcb design for a 7 segment clock for single sided milled pcbs

BOM (alternatives are also OK):
- 2x SN74HC595DR 
- 29x 150080RS75000
- 8x 10 Ohm 0805 (or 0603)
