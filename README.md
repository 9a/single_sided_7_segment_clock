# single_sided_7_segment_clock
A pcb design for a 7 segment clock for single sided milled pcbs. Designed with KiCad 10. 

BOM (alternatives are also OK):
- 2x SN74HC595DR 
- 29x 150080RS75000
- 8x 10 Ohm 0805 (or 0603)

See schematic/placement picture for assembly. It is designed to be connected to a USB-C ESP8266 D1-mini with a one to one connection via jumper wires to the pins 5V GND D4 D3 D2

The other through holes need to be connected via jumper wires.
